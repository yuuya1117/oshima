Nagano ・ 長野県 松本市

大信州酒造Daishinshu Shuzo Co., Ltd.

明治13年（1880年）、「原田屋」の屋号で創業。長野県内の複数の蔵が合併して生まれた、信州を代表する地酒の蔵。北アルプスの雪解け水が長い年月をかけて地中をめぐった伏流水と、全量契約栽培の長野県産米で醸す「天恵の美酒」。2020年に松本市へ拠点を集約し、新たな蔵の歴史を歩んでいる。

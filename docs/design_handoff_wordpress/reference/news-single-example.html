盛況のうちに終了いたしました
開催報告とお礼

2026.07.03 開催報告

開場前から、前売りチケットをお持ちのお客様が200名を超える行列を作ってくださいました。開場を待つ皆様の熱気とざわめきが、この日の盛り上がりを予感させる、忘れられない光景でした。

2026年6月27日（土）に虎ノ門ヒルズ ステーションタワーにて開催いたしました「TORASAKE -虎ノ酒- 2026」は、おかげさまで大変多くのお客様にご来場いただき、大盛況のうちに終了いたしました。

全国の酒蔵と虎ノ門ヒルズの飲食店による一日限定のペアリング体験を、多くの皆様に楽しんでいただけましたこと、実行委員会一同、心より嬉しく思っております。

御礼
ご来場いただいた皆様、ご出店・ご協力いただいた酒蔵の皆様、飲食店の皆様、そして開催にあたりお力添えをいただいたすべての関係者の皆様に、心より御礼申し上げます。

当日の様子は、ご来場者の皆様にもたくさんSNSでシェアいただきました。会場の熱気が伝わる動画をぜひご覧ください。

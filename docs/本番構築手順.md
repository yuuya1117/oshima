# 本番構築手順（レンタルサーバー編）

エックスサーバー等のレンタルサーバー（PHP + MySQL）に、
staging サブドメインを挟んで移行する手順。

URLの正は `design_handoff_wordpress/URL移行マップ.md`、
テーマの規約は `../CLAUDE.md`、切り替え時の注意は `移行手順.md` 4-2。

---

## 全体の流れ

```
0. 準備        現行サイトの控えを取る
1. ステージング  staging.torasake.com に WordPress + テーマ
2. コンテンツ投入 ← 作業量の大半
3. 検証        全URLに200が返るか
4. 本番切替     旧HTMLを退避して差し替え
```

**本番にいきなり入れないこと。** 作業中のサイトが公開されてしまい、切り戻しも難しくなる。

---

## 0. 準備 — 現行サイトの控えを取る

あとで「1本も失っていないか」を照合するための材料。切り替え後には取れない。

- [ ] 現行サイトをクロールして全URLを一覧化（Screaming Frog 等）。URL移行マップと突き合わせる
- [ ] Search Console → 検索結果のパフォーマンス → 過去6ヶ月の**流入上位URL**をエクスポート
- [ ] Search Console → リンク → **被リンクのある上位ページ**をエクスポート
- [ ] 各ページの `<title>` / `meta description` / OGP / JSON-LD を控える
      （ブラウザで「ページのソースを表示」→ head をコピー。あとでACFに原文のまま入れる）
- [ ] `/uploads/` 配下のファイル一覧を控える（FTPでフォルダごとダウンロードしておくと安心）

## 1. ステージング構築

### 1-1. サブドメインを作る

サーバーパネル → **ドメイン設定** → サブドメイン追加 → `staging`
（エックスサーバー以外でも「サブドメイン設定」に相当する項目がある）

無料SSLも一緒に有効化しておく。反映に数十分かかることがある。

### 1-2. WordPress を入れる

サーバーパネル → **WordPress簡単インストール** → staging.torasake.com を選択

- サイトURL: `https://staging.torasake.com`
- データベース: 自動生成でよい
- **PHPバージョンは 8.1 以上**（サーバーパネルの「PHP Ver.切替」で確認）

### 1-3. 検索に載らないようにする（重要）

ステージングがインデックスされると本番と重複コンテンツになる。**2重でかける。**

- [ ] 管理画面 → 設定 → 表示設定 → 「検索エンジンでの表示」にチェック
- [ ] サーバーパネル → **アクセス制限**（Basic認証）を staging に設定

### 1-4. テーマを入れる

このリポジトリの `themes/torasake` ディレクトリを、サーバーの
`/staging.torasake.com/public_html/wp-content/themes/` に丸ごとアップロードする。

- GitHubの緑の「Code」→「Download ZIP」で落として、`themes/torasake` だけを取り出す
- FTPソフト（FileZilla, Cyberduck）かサーバーのファイルマネージャでアップロード
- **`themes/torasake/` の中身ではなく、`torasake` フォルダごと**置くこと

### 1-5. ACF PRO を入れる（必須）

このテーマは repeater / relationship / options page を使うので**有料版が必要**。
無料版では動かない。

https://www.advancedcustomfields.com/pro/ で購入 → zip をダウンロード
→ 管理画面 → プラグイン → 新規追加 → プラグインのアップロード

有効化してライセンスキーを入力する。

### 1-6. テーマを有効化

管理画面 → 外観 → テーマ → **TORASAKE** を有効化。

有効化時に以下が自動で入る（冪等なので何度有効化しても壊れない）。

- 固定ページ: トップページ / お知らせ / 過去のイベント / 協賛について
- 表示設定: フロントページと投稿ページの割り当て
- 初期ターム: 開催回2件、お知らせカテゴリ3件
- リライトルール

続けて **設定 → パーマリンク設定 → 変更を保存**（何も変えずに押すだけ）。
リライトルールの再書き出しのため。これを忘れると404が出る。

### 1-7. 動作確認

- [ ] `https://staging.torasake.com/` が表示される（まだ「次回準備中」でOK）
- [ ] 管理画面の左メニューに 酒蔵 / イベント / 過去開催 / ブログ / 協賛企業 がある
- [ ] 酒蔵の編集画面にACFの項目（銘柄・ロゴ・出展銘柄など）が出ている
      → 出ていなければ ACF PRO が有効化されていない

## 3. 検証

ステージングのURLで、本番相当の全パスに200が返るか確認する。

```sh
BASE=https://staging.torasake.com
while read -r path; do
  code=$(curl -sS -u USER:PASS -o /dev/null -w '%{http_code}' "$BASE$path")
  printf '%-46s %s\n' "$path" "$code"
done <<'URLS'
/
/news/
/news/2026-07-03-event-report.html
/news/2026-06-27-当日券.html
/news/2026-05-28-matching.html
/news/2026-05-25-event-system.html
/news/2026-05-21-開催決定.html
/past/
/breweries/
/breweries/taka.html
/breweries/daishinshu.html
/events/
/blog/
/sponsors/
URLS
```

Basic認証をかけているので `-u USER:PASS` が要る。

- [ ] 上記すべて 200
- [ ] 酒蔵一覧の検索・都道府県・開催回フィルタが動く
- [ ] トップのカウントダウンが動く
- [ ] 酒蔵一覧・詳細に**価格が出ていない**
- [ ] Peatixリンクに `?utm_source=hp` が付いている
- [ ] スマホ幅で崩れない

## 4. 本番切り替え

### 4-1. バックアップ（切り戻し用）

- [ ] 本番の全ファイルをFTPでダウンロード（特に `/uploads/` と全 `.html`）
- [ ] サーバーパネルの**自動バックアップ**からも復元できるか確認しておく

### 4-2. 本番にWordPressを入れる

ステージングをそのまま複製するのが確実。

- **All-in-One WP Migration** などのプラグインでエクスポート → 本番にインポート
- または本番に新規インストールし、同じ手順（1-4〜1-6）＋コンテンツを再投入

いずれの場合も本番側で:

- [ ] 設定 → 一般 → WordPressアドレス / サイトアドレスが `https://torasake.com` になっているか
- [ ] 設定 → 表示設定 → 「検索エンジンでの表示」の**チェックを外す**（外し忘れが一番多い事故）
- [ ] 設定 → パーマリンク設定 → 変更を保存

### 4-3. 旧HTMLを退避 ★ここを忘れると方式Aが壊れる

WordPressの `.htaccess` は実ファイルがあればWPに渡さない。
旧 `.html` が残っていると、テーマのリライトが発火せず古いHTMLが出続ける（エラーは出ない）。

| パス | 扱い |
|---|---|
| `/index.html` `/news/*.html` `/past/index.html` | **退避**（移動。削除ではなく） |
| `/uploads/**` | **残す**（消すと画像検索流入とOGPが切れる） |

詳細と確認方法は `移行手順.md` 4-2。

### 4-4. 公開直後の確認

- [ ] 3章の全URLに200（今度は本番URLで、Basic認証なし）
- [ ] `/uploads/keyvisual.jpg` と `/uploads/staff.jpg` が表示される
- [ ] `curl -I https://torasake.com/news/2026-07-03-event-report.html` でWPが応答している
      （静的ファイルのままだと `Last-Modified` が古い日付で返る）
- [ ] Search Console でサイトマップを再送信
- [ ] カバレッジを1週間監視

## つまずいたときに見るところ

| 症状 | 原因 |
|---|---|
| 全ページ404 | パーマリンク設定を保存していない |
| `/breweries/` がお知らせ一覧になる | CPTの `has_archive` が false（CLAUDE.md ルール5） |
| `/news/xxx.html` が古い内容のまま | 旧HTMLが残っている（4-3） |
| ACFの項目が出ない | ACF PRO が未有効化 |
| 画像が出ない | `/uploads/` を消した、またはパスが変わった |
| 管理画面は見えるがトップが真っ白 | PHPバージョンが8.1未満 |
